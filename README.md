# ✊ Rock Paper Scissors Game ✋

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.

The player chooses Rock, Paper, or Scissors, and the computer randomly selects its choice. The game then determines the winner and updates the score.

## 🎮 Live Demo

## 📌 Features

- 🎮 Play Rock, Paper, Scissors against the computer
- 🤖 Computer makes a random choice
- 🏆 Automatically determines the winner
- 📊 Keeps track of player and computer scores
- 🔄 Reset game option
- 📱 Responsive design
- ✨ Simple and user-friendly interface
- ⚡ Fast and lightweight
- 🌐 Works directly in the browser

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page
- **CSS3** – Styling, layout, animations, and responsive design
- **JavaScript** – Game logic, random computer choices, score calculation, and DOM manipulation
